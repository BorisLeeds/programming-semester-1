#State two advantages of using version control when writing software
- Allows changes to be tracked
from the indivdiual standpoint it means that you can go back to previous working versions if you made a mistake or want to see some code you had written before and want to recover.
from the standpoint of a team, it helps them see who added what to the project as well who is currently working on which feature which can help track and identify contributions and problems.
- allows multiple people to work on one project more easily.
from the indivdual standpoint it means that you dont have to worry about losing work when working on a team and can safely edit the work without risk of messing up everyone elses work.
As a team it means that everyone can work on different parts of the project at the same time and combine it, which makes everything a lot more effecient and easier to manage.
#State one disadvantage of Git
it can be hard to understand and learn for a beginner and increases the complexity of projects and work, as there are now a lot more commands to remember and can make the work you need to do a lot more complex
