# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | lists all the items in the currently selected directory|
|     cd directory_name       | opens folder with that name in current directory|
|     cd ..                   | go back to previous folder|
|     cd -                    | moves you to your previous directory|
|     mkdir directory_name    | makes a new directory at your current location with name "directory_name"|
|     touch filename          | makes a new file called "filename"|
|     git status              | shows state of all files in directory|
|     git add -A              | adds all items to the list of items that are about to be commited|
|     git commit -m ""        | commits the selected items with the message ""|
|     git push                | pushes your changes to github|
|     git pull                | download the latest changes from github|
